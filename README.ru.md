# DSH WSL Workspace — Краткое руководство

[English](README.md) · [简体中文](README.zh.md)

**DSH работает в Windows, а проект открывается непосредственно внутри локальной WSL.**
Интерфейс, модели и сеансы DSH остаются в Windows, а команды, операции с файлами,
поиск `grep` / `glob` выполняются в выбранном дистрибутиве Linux.
Дополнительная установка DSH внутри WSL не нужна.

## Требования

DSH для Windows, работающий дистрибутив WSL и `python3`
(Python 3.8 или новее) в этом дистрибутиве.

## Установка

В менеджере плагинов DSH добавьте **Git-адрес именно этого форка**:

```text
git+https://github.com/yaelysia/dsh-wsl-workspace.git#main
```

Включите плагин, затем **полностью завершите и перезапустите основной процесс DSH**.
Одноимённый npm-пакет исходного проекта не содержит улучшений этого форка.
При обновлении проверяйте фактически установленный Git-коммит.

## Использование

Нажмите **W** рядом с настройками, выберите дистрибутив, при необходимости
пользователя Linux и каталог, например `/home/me/project`.
Обычные инструменты `read` / `write` / `edit`, `grep` / `glob` и `bash`
будут работать с проектом WSL. Файлы Windows по-прежнему доступны через
`/mnt/c/...`. При совпадающих настройках файловые операции и поиск
используют общий RPC-процесс, который освобождается после простоя.

Настройки, диагностика и ограничения по размерам и разрешениям описаны
в [английском README](README.md) и [китайском README](README.zh.md).
Горячая перезагрузка зависит от самого DSH; после обновления может
потребоваться полный перезапуск.
